# ことば学习应用全面改进方案

三项改进全部实现：**真实学习数据**、**SM-2 间隔重复复习**、**按类型扩充课程内容**。老用户云端数据自动升级，不破坏现有功能。

## 数据模型变更（核心）

`AppState` 从"存展示值"改为"存原始记录，展示值全部派生"：

```ts
// 新增字段（平滑迁移：加载时补默认值）
taskDate: string                  // 当日计划日期 'YYYY-MM-DD'，跨天自动重置任务
studyLog: Record<string, number>  // 日期 → 学习分钟数（连续天数/周图表的数据源）
quizStats: Record<TaskKind, { correct, total }>  // 各类型测验正确率
cardProgress: Record<string, CardProgress>       // 每张卡片: ease/intervalDays/dueISO/reps/lapses
lessonsCompleted: number          // 课程进度计数

// 移除（改为派生计算）: streak, weeklyMinutes, reviewCount
```

## 文件改动清单

### 1. `src/srs.ts`（新建）— 纯函数核心逻辑
- **SM-2 简化算法** `scheduleCard(progress, rating)`：忘记→重学+ease-0.2；有点难→×1.2；记得→1天/6天/×ease；很熟练→×ease×1.3，ease 限制 [1.3, 2.8]
- **派生选择器**：`streakOf(studyLog)`（连续天数）、`weekMinutes`（本周一~周日）、`dueCards`（到期+新卡混合队列，新卡每日上限 5）、`masteryOf`、`masteredCount`（间隔≥21天）、`nextIntervalLabel`（评分按钮显示"明天/4 天后"真实间隔）
- 无 React 依赖，可独立验证

### 2. `src/data.ts` — 内容扩充
- 完整 **46 个平假名**（あ行~わ行+ん，含读音和记忆提示）
- **10 个问候词汇**（おはよう、こんにちは、ありがとう等，含读音/释义）
- `buildCardPool()` 生成复习卡池（假名组 + 词汇组）
- initialState 更新为新结构

### 3. `src/types.ts` — 新类型 `CardProgress`/`QuizStat`/`Rating`，AppState 调整

### 4. `src/useLearningState.ts` — 状态管理升级
- **迁移函数**：老云端数据加载时补新字段默认值；若旧状态有已完成任务，把时长回填到今天的 studyLog；清除废弃字段
- **每日重置**：taskDate ≠ 今天 → 任务完成状态清零（新的一天新计划）
- **toggleTask 对称计时**：勾选完成任务 → studyLog[今天] += duration；取消勾选 → 减回
- 新增 actions：`rateCard`（复习评分）、`recordQuiz`（记录测验）、`completeLesson`（课程进度+1）

### 5. `src/App.tsx` — 全部页面接入真实数据
- **今日页**：真实日期（`Intl` 格式化）；本周学习时长/连续天数来自 studyLog；复习横幅显示真实到期数和组成（假名 n · 单词 n）
- **顶栏/侧栏**：连续天数徽章、复习角标、课程进度百分比全部实时计算
- **学习页**：当前课程 = 第一个未完成的课程，进度 = lessonsCompleted/课程数，完成后自动解锁下一阶段
- **复习页（重写）**：真实到期队列（按到期日排序）；四档评分调用 SM-2 调度并显示计算出的下次间隔；评分后卡片离队；队列清空显示完成总结（已复习数、下次复习日期）
- **课程弹窗（重写）**：按任务类型出题——假名（字→读音）、词汇（词→释义）、听力（TTS 播音→选字，自动朗读受 soundEnabled 控制）、复习类型直接跳转复习页；优先抽未学过的内容；**严格模式生效**：正确率 <80% 不标记完成，提示再练
- **数据页**：日期范围、周柱状图、四项指标（本周时长/任务完成率/正确率/已掌握数）、掌握度行（假名组/词汇组/听力测验/综合）全部真实计算；"本周建议"动态选最弱项

### 6. `server/index.js` — 服务端校验更新
`isLearningState` 改为校验新结构：studyLog 键数 ≤400 且值为 0~1440、cardProgress 键数 ≤500、各数值字段有限等（防滥用，结构不变则 PUT 会被拒）

### 7. `src/styles.css` — 少量新增
复习完成总结面板、测验结果反馈等复用现有设计语言

### 8. `scripts/visual-check.mjs` — 同步更新自动化验证
模拟 API 的 state 结构更新；新增复习页评分流程断言（评分后队列缩短）；课程测验流程适配新出题逻辑

## 验证步骤

1. `npm run lint` + `npm run build` 通过
2. `node scripts/visual-check.mjs`（mock API，无需数据库）：登录→完成课程→复习评分→设置变更→注册流程全链路无报错
3. `npm run test:cloud`（真实云端 MySQL 冒烟，自动建临时账户并清理）

## 不改动的部分

认证/会话/限流/同步机制（已经完善）、构建产物结构、`file://` 兼容模式均保持原样。
